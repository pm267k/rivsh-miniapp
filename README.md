# Мини-приложение группы ПМ 2.67к

Telegram Mini App для учебной группы: расписание, задания со сроками, каталог книг,
предметы и контакты. Данные живут в Google Таблице группы — приложение только показывает.

- **Страница** — этот репозиторий, раздаётся через GitHub Pages.
- **Данные** — Apps Script в аккаунте группы, отдаёт JSON после проверки.
- **Доступ** — только участникам чата: подпись Telegram `initData` + `getChatMember`.

Документация и решения — в vault: `self-development/rivsh/rivsh-miniapp.md`.
